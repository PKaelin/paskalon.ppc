# paskalON.Protocols.C37118.IntegrationTest
Integration tests of [paskalON.Protocols.C37118](../paskalON.Protocols.C37118/README.md) with a real client and server connected over the loopback interface.

Part of the [Communication solution](../README.md).


## Integration Test
The tests open TCP connections on `127.0.0.1` with free ports. No device or Docker is required: run them with `dotnet test`.
