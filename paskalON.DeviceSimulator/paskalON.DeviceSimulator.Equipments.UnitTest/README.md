# paskalON.DeviceSimulator.Equipments.UnitTest
Unit tests of [paskalON.DeviceSimulator.Equipments](../paskalON.DeviceSimulator.Equipments/README.md).

Part of the [Device Simulator solution](../README.md).


## Unit Test
All unit tests are isolated and run in-memory. External boundaries are mocked with Moq, and the tests do not depend on each other or on their execution order.
