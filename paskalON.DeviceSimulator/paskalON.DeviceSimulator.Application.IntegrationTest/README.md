# paskalON.DeviceSimulator.Application.IntegrationTest
Integration tests of [paskalON.DeviceSimulator.Application](../paskalON.DeviceSimulator.Application/README.md) together with the real equipments and Device Service domain (e.g. factories).

Part of the [Device Simulator solution](../README.md).


## Integration Test
The tests run in-memory with the real classes. No database, device or Docker is required: run them with `dotnet test`.
