# paskalON.DeviceSimulator.Service
ASP.NET Core host of the Device Simulator: Web API controllers, SignalR hub, simulation worker and publisher. It is built as a Docker image.

Part of the [Device Simulator solution](../README.md).


## Web API
The endpoints are described in [Interfaces](../Docs/Interfaces.md#web-api) and can be called with the REST Client file [paskalON.DeviceSimulator.Service.http](./paskalON.DeviceSimulator.Service.http).


## Configuration
Environment variables and secrets are described in [Configuration](../Docs/Configuration.md).
