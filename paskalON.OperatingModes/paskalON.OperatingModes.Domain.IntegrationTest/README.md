# paskalON.OperatingModes.Domain.IntegrationTest
Integration tests of [paskalON.OperatingModes.Domain](../paskalON.OperatingModes.Domain/README.md): open and closed modes and the system operating mode control working together with realistic configurations.

Part of the [Operating Modes solution](../README.md).


## Integration Test
The tests run in-memory with the real domain classes and a fake time provider. No external service or Docker is required: run them with `dotnet test`.
