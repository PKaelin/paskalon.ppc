# paskalON.OperatingModes.Application.IntegrationTest
Integration tests of [paskalON.OperatingModes.Application](../paskalON.OperatingModes.Application/README.md) together with the real domain (e.g. ramps).

Part of the [Operating Modes solution](../README.md).


## Integration Test
The tests run in-memory with the real application and domain classes and a fake time provider. No external service or Docker is required: run them with `dotnet test`.
