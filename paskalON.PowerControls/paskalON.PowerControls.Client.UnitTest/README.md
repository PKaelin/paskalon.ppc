# paskalON.PowerControls.Client.UnitTest
Unit tests of [paskalON.PowerControls.Client](../paskalON.PowerControls.Client/README.md).

Part of the [Power Control solution](../README.md).


## Unit Test
All unit tests are isolated and run in-memory. External boundaries are mocked with Moq, and the tests do not depend on each other or on their execution order.
