# paskalON.PowerControls.Service
ASP.NET Core host of the Power Control service: Web API controllers, heartbeat and metrics publisher. It is built as a Docker image.

Part of the [Power Control solution](../README.md).


## Web API
The endpoints are described in [Interfaces](../Docs/Interfaces.md#web-api) and can be called with the REST Client file [paskalON.PowerControls.Service.http](./paskalON.PowerControls.Service.http).


## Configuration
Environment variables and secrets are described in [Configuration](../Docs/Configuration.md).
