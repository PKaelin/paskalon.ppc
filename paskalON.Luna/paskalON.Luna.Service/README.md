# paskalON.Luna.Service
ASP.NET Core host of the Luna Web API: REST controllers, SignalR hubs and publishers for Luna Web. It is built as a Docker image.

Part of the [Luna solution](../README.md).


## Web API
The endpoints and hubs are described in [Interfaces](../Docs/Interfaces.md) and can be called with the REST Client file [paskalON.Luna.Service.http](./paskalON.Luna.Service.http).


## Configuration
Environment variables, secrets and `SystemConfig.xml` are described in [Configuration](../Docs/Configuration.md).
