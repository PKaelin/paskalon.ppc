# paskalON.Luna.Dto
DTOs owned by Luna: system meter summary, dependency status, system nameplate, system command response and alarm acknowledgement. The TypeScript types in `paskalON.Luna.Web/src/types` mirror these DTOs.

Part of the [Luna solution](../README.md).
