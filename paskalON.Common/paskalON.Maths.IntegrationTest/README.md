# paskalON.Maths.IntegrationTest
Integration tests of [paskalON.Maths](../paskalON.Maths/README.md) with several functions working together (calculuses).

Part of the [Common solution](../README.md).


## Integration Test
The tests run in-memory. No external service or Docker is required: run them with `dotnet test`.
