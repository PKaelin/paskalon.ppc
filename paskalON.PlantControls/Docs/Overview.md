# Plant Control Overview
Plant Control is the Power Plant Controller that manages an energy facility.

Back to the [solution README](../README.md).


## Purpose
- Plant can be different locations like Hawaii, Oregon, etc.
- Plant can be different types like BESS, Solar, Nuclear, etc.
- Plant can be scaled like BESS1, BESS2, etc.

The position of Plant Control in the PPC is shown in the [Solution Landscape](/Docs/02-Architect/SolutionLandscape.md#plant-control).
